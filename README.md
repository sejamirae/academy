# Mirae Academy

Portal de apresentação da **Mirae Academy** — plataforma de educação médica continuada para hospitais, em parceria com a RD Medicine.

🔗 **Site publicado:** https://sejamirae.github.io/academy/

## Estrutura

- `index.html` — página única (landing page) do portal
- `img/` — imagens da plataforma (trilhas, onboarding, aulas, flashcards, Visual Memory, AnimaMED, certificação, dashboard) e logos

## Publicação

O site é servido via **GitHub Pages** a partir da branch `main` (raiz do repositório).
